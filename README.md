# 応援ガチャ サイト

## 開き方
`index.html` をブラウザで開くだけで動作します（フォルダ構成を崩さずそのまま使ってください）。

## 画面の流れ
1. **ログイン画面**：2026/10/10までの残り日数を表示し、「タップして開始」を押すと `ouengassen.mp4` が再生される。再生が終わると自動でメイン画面へ。
2. **メイン画面**：左＝2026/10/03までの「競技大会まであと◯日」、中央＝「ガチャを引く」ボタン、右＝空欄。
3. **ガチャ演出**：ボタンを押すと `ouen/ouen1〜6.mp4` からランダムに1本再生 → 終わると `img` フォルダからランダムな1体の画像を表示し、同名の `gacha` フォルダの音声を再生。
4. **キャラ一覧画面**：音声が終わると自動遷移。`img` フォルダの全キャラを、画像を暗転させた状態＋ファイル名で一覧表示。「メインへ戻る」でメイン画面に戻れます。

## キャラクターを追加する方法
1. `img/` フォルダに画像（例：`きつねくん.png`）を追加
2. `gacha/` フォルダに **同じ名前** の音声ファイルを追加（例：`きつねくん.wav`）
3. `script.js` の先頭にある `CHARACTERS` 配列に1行追加：
   ```js
   { name: "きつねくん", img: "img/きつねくん.png", audio: "gacha/きつねくん.wav" },
   ```
これだけでガチャの抽選対象・一覧画面に反映されます。

## 応援動画を増やす／減らす場合
`ouen/` フォルダにファイルを追加し、`script.js` の `OUEN_VIDEOS` 配列にパスを追記・削除してください。
